# Student Profile App — ITP107 Midterm Lab 2

An interactive Student Profile Application built with Flutter, showcasing
personal and academic information using 17 different Flutter widgets.

## Getting Started

1. Make sure you have the Flutter SDK installed: https://docs.flutter.dev/get-started/install
2. From this project folder, fetch dependencies:
   ```
   flutter pub get
   ```
3. Run the app on a connected device / emulator:
   ```
   flutter run
   ```

## Before submitting

Open `lib/main.dart` and edit the `_ProfileData` class at the top with your
own real information (name, age, birthday, address, hobby, motto, course,
year level, section, and academic info). Also swap in your own photo URL
or asset for `photoUrl`.

## Widgets used

Scaffold, AppBar, Container, Text, Image, Card, Column, Row, Padding,
SizedBox, CircleAvatar, Icon, ElevatedButton, TextButton, Divider, ListTile,
SingleChildScrollView.
